ขายพระบ้าน — FIXED V6
========================

ฐานพัฒนา
---------
V6 นี้พัฒนาต่อจาก KhaiPhraBan_FIXED_V5 โดยตรง
ไม่ย้อนกลับไปใช้ V4/V3 และคงระบบ V5 เดิมทั้งหมด:
- สมาชิก / ลงประกาศ / Admin
- แชท + ส่งรูป
- Firebase Push Notification
- โทร / ดูเบอร์ / แชท / สนใจองค์นี้
- แจ้งเตือนอัตโนมัติ
- หน้าแรกแก้จาก Admin

สิ่งที่เพิ่มใน V6
-----------------
1) ระบบแต้ม / Wallet
- สมาชิกทุกคนมีกระเป๋าแต้มแยก
- บันทึกประวัติแต้มทุกครั้ง
- Admin เพิ่ม/หักแต้มได้
- ป้องกันยอดติดลบ

2) ระบบเติมแต้ม
- Admin จัดการแพ็กเกจเติมแต้ม
- สมาชิกเลือกแพ็กเกจและส่งคำขอจากแอป
- Admin ตรวจยอดเงินจริงแล้วกดอนุมัติ/ปฏิเสธ
- เมื่ออนุมัติ แต้มเข้ากระเป๋าและบันทึกธุรกรรมทันที
หมายเหตุ: V6 ใช้ manual approval ยังไม่ได้ผูก Payment Gateway เพราะไม่มี credential/payment provider ใน V5

3) โพสต์พรีเมียม / พื้นที่โฆษณา
- Admin ตั้งแพ็กเกจพรีเมียมได้ เช่น 20 แต้ม/1 วัน, 50 แต้ม/3 วัน, 100 แต้ม/7 วัน
- สมาชิกเลือกประกาศที่อนุมัติแล้วและใช้แต้มซื้อ
- หักแต้มแบบ transaction + row lock
- โพสต์พรีเมียมขึ้นพื้นที่เด่นด้านบนหน้าแรกทันที
- มี badge พรีเมียมบนการ์ดและหน้ารายละเอียด
- ซื้อซ้ำไม่ได้ขณะพรีเมียมเดิมยังไม่หมดอายุ

4) หน้าแรก UI ใหม่
- ส่วน "โพสต์พรีเมียม" ด้านบน
- ส่วน "โพสต์ทั่วไป" แยกชัดเจน
- โพสต์ทั่วไปเลือกมุมมอง "รายการ" หรือ "ตาราง" ได้
- ค่าเริ่มต้นเป็นมุมมองรายการ

5) Admin ใหม่
- /admin/points.php : ตรวจคำขอเติมแต้ม + เพิ่ม/หักแต้มสมาชิก
- /admin/premium.php : จัดการแพ็กเกจเติมแต้ม + แพ็กเกจพรีเมียม + ดู/ยกเลิกแคมเปญ
- /admin/listings.php : แสดงสถานะพรีเมียม
- /admin/update_system.php : ติดตั้ง/ตรวจ schema V6

Backend อัปเกรดจาก V5
----------------------
1. สำรองฐานข้อมูลและโฟลเดอร์ backend ปัจจุบันก่อน
2. อัปโหลดโฟลเดอร์ backend จาก V6 ทับไฟล์ V5
3. เข้า Admin > อัปเดตระบบ
4. กด "ตรวจและติดตั้ง V6"
5. เข้า Admin > พรีเมียม เพื่อตรวจราคาแพ็กเกจ
6. เข้า Admin > แต้ม/เติมแต้ม เพื่อทดสอบเพิ่มแต้มให้บัญชีทดสอบ
7. ติดตั้ง APK V6 แล้วทดสอบ:
   - Login
   - แต้ม > ส่งคำขอเติมแต้ม
   - Admin อนุมัติ
   - แต้มเข้าบัญชี
   - เลือกประกาศ approved > ซื้อพรีเมียม
   - หน้าแรกเห็นประกาศในส่วนพรีเมียม

Migration SQL สำรอง:
backend/database/migration_v6.sql

การทดสอบ/ข้อจำกัดในชุดที่ส่ง
---------------------------
- PHP ทุกไฟล์ผ่าน php -l แล้ว
- พยายามรัน Gradle assembleDebug แล้ว แต่ environment ที่ใช้แพ็กไฟล์ไม่มีอินเทอร์เน็ตและไม่มี Gradle 8.13 cache
  จึงหยุดที่ขั้นดาวน์โหลด Gradle wrapper ไม่ใช่ compile error ของ source
- ให้เปิดใน Android Studio ที่มีอินเทอร์เน็ตครั้งแรกเพื่อ Gradle Sync/Build APK

ความหมาย "พื้นที่โฆษณา" ใน V6
------------------------------
V6 ตีความเป็น "พื้นที่เด่นสำหรับประกาศสินค้าพรีเมียมบนหน้าแรก"
ยังไม่ได้ทำ banner image ad แยกจากประกาศสินค้า เพราะ V5 ไม่มีโมเดล banner/ad creative เดิม
