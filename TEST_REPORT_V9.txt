8) Security Review — Order/Rating/Chat
======================================
Order:
- buyer = current token user
- seller/title/price = listing from Server
- verified bank = identity_verifications.status='verified' from Server
- bank snapshot inserted by Server in create_order transaction
- Android has no seller bank fields in create_order request

Rating:
- current token user must equal order.buyer_id
- seller != current user
- status must completed
- 1..5 validated Server
- UNIQUE seller_reviews.order_id
- transaction + FOR UPDATE on Order prevents concurrent duplicate rating

Chat:
- unread current user query counts sender_id != current user only
- room authorization runs before mark-read
- mark read WHERE sender_id != current user AND read_at IS NULL
- send_message/send_chat_image/Push case logic retained
