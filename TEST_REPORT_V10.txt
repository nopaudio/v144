Android build ที่พยายามรัน
---------------------------
คำสั่ง:
  bash gradlew :app:compileDebugKotlin --no-daemon

ผล:
  ENVIRONMENT BLOCKED ก่อนถึง Kotlin compiler

สาเหตุจริง:
- Gradle Wrapper ต้องดาวน์โหลด Gradle 8.13
- Environment นี้ไม่มี network/DNS สำหรับดาวน์โหลด
- ~/.gradle ไม่มี Gradle 8.13 distribution cache
- ไม่มี system `gradle` หรือ `kotlinc` สำรอง

ข้อความหลัก:
  Downloading Gradle 8.13...
  java.net.ConnectException
  Caused by: java.nio.channels.UnresolvedAddressException

ดังนั้น:
- ห้ามสรุปว่า Android compile ผ่าน
- ห้ามสรุปว่า Android compile fail เพราะ source
- สถานะที่ถูกต้องคือ “ยัง compile จริงไม่ได้เพราะ environment”
