ตลาดพระออนไลน์ — FIXED V7
=================================

รุ่นนี้ต่อยอดจาก V6 โดยเน้นให้การซื้อพรีเมียมและเติมแต้มเห็นผลชัดเจนในแอป พร้อมเพิ่มเครื่องมือแอดมิน

สิ่งที่เพิ่ม/แก้ใน V7
---------------------
1) พรีเมียม
- หลังซื้อพรีเมียม UI เปลี่ยนสถานะทันที แล้วซิงก์กับเซิร์ฟเวอร์ซ้ำ
- หน้าแรก/หน้ารายการของฉัน/หน้ารายละเอียดสะท้อนสถานะพรีเมียม
- ไอคอนดาวพรีเมียมมีเอฟเฟกต์ pulse กระพริบเบา ๆ
- แอดมินยังตั้งราคาแต้มและจำนวนวันของแพ็กเกจพรีเมียมได้

2) เติมแต้มแบบโอนเงิน + สลิป
- ยกเลิกการเลือกแพ็กเกจเติมแต้มในหน้าใช้งาน
- ลูกค้ากรอกยอดเงินเอง
- แอปแสดงธนาคาร ชื่อบัญชี เลขบัญชี/PromptPay ที่แอดมินตั้ง
- ลูกค้าแนบรูปสลิปและส่งรออนุมัติ
- Android ย่อ/บีบอัดรูปขนาดใหญ่ก่อนอัปโหลด และใช้ sampled decode บน Android รุ่นเก่าเพื่อลดปัญหา memory
- แอดมินตรวจสลิปและกดอนุมัติ ระบบเพิ่มแต้มแบบ transaction ป้องกันการอนุมัติซ้ำ
- อนุมัติแล้วระบบส่ง Push แจ้งผู้ใช้

3) ผู้ใช้งานออนไลน์
- หน้าแรกมีชิปแสดงจำนวน session ที่ active ภายใน 15 นาทีล่าสุด
- ใช้ heartbeat จริงจากเครื่องที่เปิดแอปใน foreground ไม่สร้างตัวเลขผู้ใช้งานปลอม
- heartbeat หยุดเมื่อแอปออกจาก foreground

4) แชร์ Facebook
- หน้ารายละเอียดประกาศมีปุ่มแชร์ไป Facebook
- เพิ่ม share.php สำหรับ Open Graph เพื่อให้ Facebook อ่านชื่อ/รายละเอียด/รูปประกาศได้

5) ชื่อแอป
- เปลี่ยนชื่อที่แสดงเป็น “ตลาดพระออนไลน์”
- ปรับชื่อใน Android, หน้าแอดมิน, Terms และ Privacy

6) แชท
- ปรับหน้า Inbox และห้องแชทใหม่ให้เป็นงาน UI แบบมืออาชีพ
- มี avatar ตัวอักษร, bubble ข้อความ, ช่องพิมพ์/แนบรูป และสถานะโหลดที่ชัดขึ้น
- polling แชทเดิมยังคงทำงาน

7) ประกาศและแจ้งเตือน
- ตอนบันทึกประกาศในแอดมินสามารถส่ง Push ไปพร้อมกัน
- แอปรีเฟรชประกาศเมื่ออยู่ foreground
- เพิ่มหน้าแอดมิน “แจ้งเตือน” สำหรับส่งทันทีหรือกำหนดวัน/เวลาและข้อความเอง
- ระบบแจ้งเตือนสุ่มเดิมใน Android ยังเก็บไว้ ไม่ได้ลบ

8) แจ้งปัญหา / รายงานผู้ใช้
- หน้ารายละเอียดมีปุ่ม “แจ้งปัญหา / รายงานผู้ใช้”
- เลือกหมวด เช่น สงสัยโกง, ปัญหาชำระเงิน, ประกาศน่าสงสัย ฯลฯ
- รายงานเข้าแอดมิน
- แอดมินเปลี่ยนสถานะเรื่อง, ปิดเรื่อง, ยกเลิก หรือระงับบัญชีผู้ถูกรายงานได้

วิธีอัปเดตจาก V6
-----------------
1. สำรองไฟล์เว็บไซต์และฐานข้อมูลก่อน
2. อัปโหลดไฟล์ในโฟลเดอร์ backend ของ V7 ทับไฟล์ระบบเดิมตามโครงสร้างเดิม
3. เข้า Admin > “อัปเดตระบบ” แล้วกด “ตรวจและติดตั้ง V7” 1 ครั้ง
   - หน้านี้ใช้ ensure_v7_schema() อัปเกรดฐานข้อมูลจาก V6 แบบตรวจคอลัมน์ก่อน
   - migration_v7.sql มีไว้เป็นทางเลือกสำหรับผู้ดูแลที่อัปเดตฐานข้อมูลเอง
4. เข้า Admin > “แต้ม/เติมแต้ม”
   - ตั้งธนาคาร
   - ชื่อบัญชี
   - เลขบัญชี/PromptPay
   - อัตราแต้มต่อ 1 บาท
   - ยอดเติมขั้นต่ำ
5. ตรวจว่า Firebase Service Account เดิมพร้อมใช้งาน หาก Push ยังไม่พร้อม หน้า “อัปเดตระบบ” จะแจ้งเตือน
6. สำหรับ “แจ้งเตือนตั้งเวลา” ต้องตั้ง Cron ของโฮสติ้งให้รันทุก 1 นาที:
   php /PATH_TO_YOUR_BACKEND/cron/notifications.php
   ให้แทน PATH_TO_YOUR_BACKEND ด้วย path จริงบนเซิร์ฟเวอร์
7. Build Android รุ่นใหม่จาก KhaiPhraBan2/android-app
   - versionCode 5
   - versionName 1.4.0
   - ตรวจ API_BASE_URL ให้ตรงกับโดเมนจริงของระบบก่อน release

หมายเหตุสำคัญ
-------------
- PHP ในแพ็กนี้ผ่าน php -l ทุกไฟล์แล้ว
- ในสภาพแวดล้อมที่จัดทำแพ็กนี้ Gradle Wrapper ต้องดาวน์โหลด Gradle 8.13 แต่ไม่มีเครือข่าย จึงไม่สามารถรัน compileDebugKotlin จริงได้
- มีการตรวจโครงสร้างวงเล็บ/brace ของ Kotlin และตรวจ signature ของจุดที่แก้แบบ static แล้ว
- ตัวเลข “ออนไลน์” เป็นข้อมูลกิจกรรมจริงในช่วง 15 นาที ไม่ใช่ตัวเลขจำลอง
- รูปสลิปฝั่งแอปถูกย่อก่อนส่ง แต่ PHP/เว็บเซิร์ฟเวอร์ยังมี upload/request limits ของตัวเอง หากรับไฟล์จาก client อื่นโดยตรงควรตั้งค่า PHP ให้เหมาะสม
- อย่านำ Firebase private key หรือข้อมูลลับออกมาไว้ใน public_html
